# Suretek brand sources

- `suretek-logo.png` is the original logo extracted without alteration from the user-supplied Suretek_HireAI_HRMS_Complete_Blueprint.docx (`word/media/770618557be08e9291f0bc4d8744976a7be97c87.png`).
- Website: https://www.suretekinfosoft.com/. Its `assets/css/style.css` defines primary red `#a22426`, body font Poppins and display font Teko. Tokens reuse these brand choices; the white sidebar and pale rose surfaces follow the document's retained dashboard designs.
- Poppins 400/500/600/700 and Teko 600 are Google Fonts files downloaded from fonts.gstatic.com. The corresponding SIL Open Font License files are included here from google/fonts, `ofl/poppins/OFL.txt` and `ofl/teko/OFL.txt`.

All fonts and images are served locally through Vite's hashed assets. No external font stylesheet, tracker, third-party image request or inline script is required.
